## Branch convention

Each major Odoo version has its own branch:

- `19.0` — Odoo 19 Community & Enterprise (current default)

Module versioning follows the Odoo standard `<odoo-major>.<odoo-minor>.<module-major>.<module-minor>.<patch>` (for example `19.0.1.0.0`).
