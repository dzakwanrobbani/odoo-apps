Indonesia Shipping Cost — Website Checkout

Free LGPL-3 companion add-on for id_shipping_cost. Adds the eCommerce-specific touches: calibration banner on /shop/checkout and a JSON rate endpoint for storefront customisations.

LGPL-3 · Free auto_install Odoo 19

What this adds

  • Calibration banner on /shop/checkout. Inherits website_sale.delivery_form. Visible only when an id_offline carrier appears in the delivery method list and the operator has not yet ticked Settings > Inventory > Indonesia Shipping > Rates Calibrated for Production.
  • JSON endpoint POST /id_shipping/calculate. Returns the full sorted rate matrix (provider, service, price, ETD) for the current cart's origin/destination/weight. Useful for storefront customisations or pre-checkout estimators.
  • Auto-install the moment both id_shipping_cost and website_sale are present. No manual setup.

The actual courier picker reuses Odoo's built-in delivery method dropdown — every delivery.carrier configured by the merchant with delivery_type='id_offline' shows up automatically. No fork of website_sale.

Requires

This is a thin companion. It needs the paid parent id_shipping_cost to do anything useful — the rate matrix, courier picker, settings panel, and calibration logic all live there.

Installation

  1. Install the paid parent id_shipping_cost from apps.odoo.com.
  2. Make sure website_sale (eCommerce) is installed.
  3. This module installs automatically — no manual action needed.
  4. (Recommended) Open Settings > Inventory > Indonesia Shipping, calibrate the bundled rates against your contracted courier prices, then tick Rates Calibrated for Production to remove the warning banner from the storefront.
